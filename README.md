# Sky Hop — Zero browser publishing test

Maintainer-owned test of an ordinary Java game compiled locally by Zero with WebFX.

Click or press Space to start/flap. P pauses, R restarts, M toggles sound.
The bundled bird, sky and pipe artwork is original generated artwork; music and effects are original procedural composition/synthesis.

This test deploys the exact locally validated build; GitHub Actions only validates and extracts the bundle. No student data.
